# PodCherry releases

Downloads for **PodCherry**, a macOS podcast player and CD ripper with a
console-style menu.

## Install

1. Open the [latest release](https://github.com/Podcherry/podcherry-releases/releases/latest)
   and download the `.dmg`.
2. Drag PodCherry to Applications.
3. The first time, **right-click → Open**. PodCherry isn't notarised by Apple
   yet, so macOS asks once whether to trust it.

Requires an Apple Silicon Mac.

## Updates

PodCherry checks this page shortly after launch and offers to install new
versions itself, so you only download once. Every update is signed, and the
app refuses any build that isn't.

This repository holds release files only. Each release's notes say what changed.
